# 09_Templates

> **Active Package Note:** This folder belongs to `Optimaks Document Library v1.7.9.4-project-baseline-governance`.  
> v1.7.9.4 adds generic project baseline governance on top of v1.7.9.3 agency skill registry and v1.7.9.2 layout normalization. It does not hard-code a single MVP scope into the Constitution.


Reusable templates for the active Optimaks document library. Some templates originated in earlier versions and remain active where listed in `01_Constitution/ACTIVE_STANDARDS_INDEX.md`.

This folder includes templates for Change Requests, GitHub Issues, AI Context Packages, Gemini Research Digest, AI Issue Execution Prompts, Pull Request Review, and Business Strategy Review.

## v1.5.4 Business Strategy Template

- `TPL-BIZ-001_Strategy_Review_Template.md`

Use this template when converting market research, competitor research, pricing assumptions, GTM ideas, or sales scripts into approved Optimaks strategy documents.
