# TPL-DEV-030 Purpose-first Filing Rule Insert

Use this insert inside Issue prompts for Codex / Antigravity.

```text
Filing Rule:
File outputs by purpose first, file extension second.

Formal application code must stay in normal project folders:
app/, src/, components/, lib/, supabase/, docs/.

Issue records must stay in:
20_Issues/MVP01/ISSUE-XXX-short-name/.

If you generate a file and are unsure where it belongs, place it in:
20_Issues/MVP01/ISSUE-XXX-short-name/_needs_review/

Then record the reason in FILE_CHANGE_LOG.md and DONE_REPORT.md.
Do not create new top-level folders unless the issue explicitly allows it.
```
