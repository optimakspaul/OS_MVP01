# CLT-009 — Client Onboarding and Launch Intake Checklist

**Status:** Active in v1.6.0  
**Type:** Controlled client delivery checklist  
**Referenced by:** CURRENT_CONSTITUTION.md

---

## 1. Purpose

This checklist standardizes the information Optimaks must collect before setting up a new client workspace, demo, production deployment, billing setup, or launch.

The constitution defines that this checklist is mandatory. This file defines the detailed fields.

---

## 2. Usage Rule

Before starting formal client setup, confirm one of the following:

```text
CLT-009 completed
CLT-009 partially completed with founder-approved exception
CLT-009 not required because the work is internal/demo-only and no real client data is used
```

If incomplete, record the missing items and risk.

---

## 3. Company Information

Collect:

```text
Company legal name
Trading name
UEN / registration number if available
Main contact person
Contact role/title
Contact email
Contact mobile / WhatsApp
Business address
Operating hours
```

---

## 4. Brand Information

Collect:

```text
Logo files
Brand colors
Brand fonts if any
Preferred tone of voice
Existing slogan / tagline
Company description
Service promise
Before/after photos if relevant
```

---

## 5. Domain / Website Access

Collect or confirm:

```text
Existing domain name
Domain registrar
DNS access owner
Current website URL
Current hosting provider
CMS access if any
Website admin access if required
Whether Optimaks may edit DNS
Whether Optimaks may publish preview / production site
```

Important: Do not store passwords in Git or uncontrolled documents.

---

## 6. Google Business Profile

Collect or confirm:

```text
Google Business Profile URL
Business category
Service areas
Review status
Access owner
Whether Optimaks is invited as manager
Photos available for use
Business hours
Phone number shown publicly
```

---

## 7. WhatsApp Number

Collect:

```text
WhatsApp number for leads
Whether it is personal WhatsApp, WhatsApp Business, or API-capable number
Default reply message
Who receives notifications
Escalation contact
Whether WhatsApp automation is allowed
```

---

## 8. Email / Notification Receiver

Collect:

```text
Main notification email
Backup notification email
Sales/admin recipient
Billing recipient
Support recipient
Whether lead notifications should go to email, WhatsApp, CRM, or all
```

---

## 9. Service Area

Collect:

```text
Service locations
Excluded locations
Travel surcharge rules if any
Emergency / express service availability
Normal appointment time windows
Public holiday policy
```

---

## 10. Pricing / Package

Collect:

```text
Selected Optimaks plan: Lite / Standard / Plus / Pro / Custom
Setup fee
Monthly fee
Contract duration
Included modules
Optional add-ons
Client-approved package description
Founder-approved exceptions if any
```

---

## 11. Photos / Logo / Reviews

Collect:

```text
Logo
Company photos
Service photos
Team photos
Before/after photos
Customer review screenshots or links
Permission to use photos/reviews in demo or live site
```

---

## 12. Admin User

Collect:

```text
Primary admin name
Primary admin email
Admin role
Backup admin
Required staff users
Permission level required
Whether staff should receive login invitation
```

---

## 13. Payment / Invoice Information

Collect:

```text
Billing company name
Billing email
Billing address
UEN / tax number if applicable
Payment method
Invoice frequency
Payment due terms
Deposit / milestone rule
PayNow / bank / payment link details if applicable
```

Do not store sensitive banking credentials or passwords in uncontrolled files.

---

## 14. Demo Data Approval

Confirm:

```text
Can Optimaks use sample/demo data?
Can Optimaks use real client data in preview?
Can Optimaks show the demo to third parties?
Should names, phone numbers or emails be anonymized?
Who approves demo content?
```

Default rule:

```text
Use mock data unless the client explicitly approves real data usage.
```

---

## 15. Launch Gate

Before production launch, confirm:

```text
Company info complete
Brand info complete
Domain/DNS status confirmed
Google Business Profile status confirmed
WhatsApp and notification channels tested
Service area confirmed
Plan/package confirmed
Photos/reviews approved
Admin user created/invited
Payment/invoice info confirmed
Demo data approval status recorded
Preview tested
Founder approval recorded
```
