# ISSUE-009 Industry Template Notes

**Issue:** ISSUE-009
**Title:** Industry Template Foundation
**Project:** MVP01
**Phase:** Phase 2 - Module Foundation

---

## 1. Purpose

ISSUE-009 defines the first MVP01 industry template at documentation and architecture level.

The template applies the ISSUE-008 Starter-depth module library to one concrete industry pattern without creating implementation files, database structures, RLS, UI, or runtime template logic.

---

## 2. Primary Industry Template

```text
Template Name: Aircon / Home Service Starter Template
Template Type: Starter-depth industry template
Primary User: SME owner / admin
Target Business Type: Aircon service, home service, or similar field-service SME
MVP01 Scope: Starter Complete + Optimaks OS Basic
```

---

## 3. Template Concept

The template is a reusable operating pattern for MVP01 demo, planning, and later implementation work.

It is not:

```text
a separate product
a separate codebase
a database schema
a template table
a module table
an entitlement system
an RLS policy layer
an app implementation
```

---

## 4. Starter-depth Included Scope

MVP01 includes only Starter-depth template guidance for:

```text
request capture
lead conversion
customer profile context
estimate / quote guidance
manual booking / appointment scheduling
payment status / manual tracking
maintenance / follow-up reminder
basic monthly / operational report
```

---

## 5. Reserved Scope

Reserved for later approved MVPs or workpacks:

```text
multi-industry marketplace
template builder UI
template tables
module tables
entitlement logic
AI automation
Grow / Pro / Platform depth
multiple live industry templates
advanced workflow variations

```
