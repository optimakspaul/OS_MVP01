# MVP01_SCOPE_BASELINE.md

## 1. Project Definition

MVP01 = Core Foundation + Solo Complete + Flow Basic + Command Reserved + Owner Console Basic.

## 2. Target User / Business Objective

- Target user: Optimaks founder and first SME / field-service pilot clients.
- Business problem: Build a repeatable, sellable, and controlled workflow automation baseline without overbuilding advanced SaaS features too early.
- Primary value: Provide a practical foundation for lead capture, customer / job workflow, owner visibility, manual-assisted operations, and future controlled expansion.

## 3. Included Scope

The following are included in this project baseline:

- Core workspace and tenant foundation.
- Next.js app foundation.
- Supabase client, environment foundation, P0 tables, indexes, triggers, auth, profiles, RLS helper functions and policies.
- Client workspace foundation.
- App shell and shared UI foundation.
- Lead, customer, booking, job, invoice, payment status, review, maintenance reminder, and notification foundations at MVP depth.
- Manual-assisted WhatsApp workflow.
- Manual payment tracking.
- Customer lightweight access.
- Technician lightweight task / job card.
- Core PDF generation, limited to the ISSUE-013 invoice tracker boundary. Full PDF automation remains reserved.
- Owner Console Basic.
- GitHub / CI / deployment governance and issue handoff flow.

## 4. Reserved Scope

The following are reserved for later project / MVP / phase unless change control approves otherwise:

- Full customer portal.
- Full PDF automation.
- Technician login as a complete role system.
- WhatsApp API automation.
- Payment gateway integration such as Stripe, HitPay, or PayNow automation.
- Advanced Command features.
- Advanced analytics, complex installment engine, auto-refund, auto-suspension, and full billing automation.
- Multi-tenant SaaS expansion beyond MVP01 foundation.

## 5. Excluded Scope

The following are excluded from this project baseline:

- Unapproved scope expansion outside MVP01.
- Autonomous multi-agent execution without founder review.
- Production deployment without preview / staging / production gate approval.
- Direct edits to secrets or live client data outside approved standards.
- Replacing the Constitution with agency-agent behavior.

## 6. Non-Goals

This project must not attempt to solve:

- Every future Optimaks product line.
- Full enterprise SaaS feature parity.
- All payment, tax, refund, and suspension automation.
- All industry templates at once.
- All Command-level quality management features before real client validation.

## 7. Feature Unlock Rule

Reserved or excluded features cannot be implemented without:

1. Impact Review
2. Placement Decision
3. Change Control Log Entry
4. Baseline Update, if approved

## 8. AI Scope Rule

AI must not treat reserved or excluded scope as available implementation work.
