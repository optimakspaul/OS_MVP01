## 2. Project Definition

MVP01 is the first executable Optimaks product baseline for Starter Complete and Optimaks OS Basic.

The project focuses on one primary industry template, shared core foundations, module library foundation, a complete Starter-depth operation flow, and the minimum Optimaks OS Basic layer needed for onboarding, client tracking, workspace links, demo readiness, and release handover.

## 3. Project Objective

This project exists to:

- Establish the repo, constitution, AI Harness, and issue-chain execution baseline.
- Build a sellable and demo-able Starter Complete workflow for the first primary industry template.
- Keep Grow, Pro, full Platform, AI, marketplace, and advanced automation capabilities reserved for later MVPs unless change control approves otherwise.
- Keep Optimaks OS Basic limited to onboarding, client list, plan status, workspace link, demo, and release support.
