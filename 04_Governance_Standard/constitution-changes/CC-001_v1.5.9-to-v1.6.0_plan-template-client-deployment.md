# CC-001 — Constitution Change Record

**Change:** v1.5.9 to v1.6.0  
**Date:** 2026-05-19  
**Status:** Approved  
**Release Name:** Plan, Template, Client Onboarding and Deployment Governance

---

## 1. Change Level

```text
Level 2 — Process and documentation execution impact
Level 4 — Product architecture / delivery model / client deployment impact
```

---

## 2. Reason

The founder discussion introduced operating rules that affect more than one issue:

```text
- Plan tiers such as Lite / Standard / Plus / Pro should be controlled by configuration and feature toggles.
- Industry-specific templates should be workflow presets rather than separate codebases.
- The Optimaks admin platform may manually activate plan/template/module settings first, with automation later.
- New client onboarding must be standardized before demo, production deployment, billing setup or launch.
- Existing MVP-01 batch 1-18 files should not be rewritten blindly when the constitution changes.
- Visual concepts should be decomposed into MVP scope and 20_Issues before implementation.
```

2026-05-19
