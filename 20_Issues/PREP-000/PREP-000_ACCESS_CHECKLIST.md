# PREP-000 Access Checklist

## GitHub

```text
[ ] GitHub repo exists
[ ] Founder has admin access
[ ] Repo can be cloned
[ ] Branch can be created
[ ] Pull Request can be opened
```

## Local

```text
[ ] Node installed
[ ] npm installed
[ ] npm install works
[ ] npm run dev works or issue is documented
```

## Supabase

```text
[ ] Supabase project exists
[ ] Supabase URL copied to local .env.local
[ ] Supabase anon key copied to local .env.local
[ ] Supabase service role key stored safely
[ ] Service role key is not exposed in frontend
```

## Vercel

```text
[ ] Vercel account exists
[ ] Vercel can import GitHub repo
[ ] Environment variable screen is accessible
[ ] Preview deployment can be configured later in ISSUE-003
```

## AI Tools

```text
[ ] Codex can access repo/workspace
[ ] Antigravity can access repo/workspace
[ ] AI issue prompt template exists
[ ] DONE report template exists
```
