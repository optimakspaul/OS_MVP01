# PROD-005 — Social Media Documentation Boundary and Future Module Notes

**Version:** v1.7.4-clean  
**Status:** Defined, not implemented  
**Classification:** Development documentation / future roadmap reference

---

## Purpose

This document records the Social Media topic as a future documentation and workflow area without turning it into an active MVP01 product module.

---

## Current Decision

Social Media is not part of Core Foundation.
Social Media is not an active MVP01 coding module.
Social Media may be documented for future client delivery, GTM, content workflow, and marketing operations.

---

## Allowed in MVP01

- social media links
- follow-us display section
- promo / campaign CTA display
- Google Review / social proof section

---

## Not in MVP01

- auto posting
- platform API integrations
- content scheduling
- AI caption generation
- social analytics dashboard
- cross-platform campaign automation

---

## Future Expansion Path

```text
Documentation first
↓
GTM / client content workflow
↓
Growth campaign tracker
↓
Pro automation module, only if validated by real client demand
```
