# V1.7.9.4 Project Baseline Governance Release Report

**Version:** v1.7.9.4-project-baseline-governance  
**Purpose:** Add generic MVP / project baseline governance without hard-coding MVP01.

---

## 1. What Changed

This release adds a reusable governance layer for all MVPs and projects.

It defines how every MVP / project should be:

```text
- scoped
- phased
- mapped to issues
- locked as a baseline
- changed through change control
- read by AI before execution
```

---

## 2. What This Does Not Do

This release does not create, define, or lock MVP01.

MVP01-specific files will be added later inside the project layer.

```text
Do not put MVP01 phase / issue details inside the Constitution.
```

## 4. Architectural Correction

Correct layering:

```text
Constitution = generic governance rules
STD-DEV-049 = generic project baseline standard
TPL-DEV-041–046 = reusable project templates
12_Projects/[PROJECT] = concrete project baseline
```

```text
Constitution = MVP01 scope / phase / issue list
```
