---

## 2. Why This Change Is Needed

The founder's desired working mode is:

```text
Founder only selects issue and gives prompt.
Codex / Antigravity executes the issue.
AI tool creates DONE.md.
Founder reviews / tests / merges.
```

Without a standard, every issue would require repeated explanation of:

```text
checklist
completion report
changed files
rollback plan
merge readiness
scope check
secret safety
constitution version used
```

v1.5.9 moves these repetitive actions into reusable standards and templates.
