## 4. Key governance conclusion

The constitution should not contain every operational checklist field. Instead:

```text
CURRENT_CONSTITUTION.md = mandatory rule and controlled reference
CLT-009 = detailed onboarding checklist fields and launch intake form
```

This keeps the constitution readable while giving CLT-009 official governance force.

---

## 5. No silent rewrite rule

v1.6.0 does not silently rewrite completed MVP-01 20_Issues or batches. It creates a controlled decision framework for deciding whether existing files require:

```text
- no action
- forward-only adoption
- supplemental note
- affected issue review
- new issue / change request
```
